Hi readers, this tool was created for myself to allow one button change display settings.
Basic idea - I'd like to be able to quick switch between basic "office" mode to "game" mode (for example to reveal shadows).

Testing UI now, please let me know if something doesn't work properly.
Few tips:
Right-up gear is theme selector, switching between system/light/dark theme.
Profile buttons can be renamed by double-clicking on them.

Current limitations - Windows 10/11, NVIDIA videocard (basic settings except Digital vibrance and Hue should work, but need to be tested).
